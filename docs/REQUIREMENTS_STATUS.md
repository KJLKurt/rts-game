## Conditional, future and supplemental scope

The original permits several biomes and a subset of modes now; eight biome examples, naval expansion, online multiplayer and cloud synchronization are future work. Formation/group systems and a manual graphics-quality selector are conditional. Named battle slots, an unrestricted visual scripting editor and full battlefield screen-reader navigation were not original mandatory features. A useful documented subset is permitted by section 53; broken shipped behavior is not.

Later discussions separately requested theme/style packs and fuller directional animation. The current candidate has one coherent sprite theme, four biome palettes, procedural motion and three attack strips. Those supplemental requests remain separately tracked in [COMMERCIAL_READINESS.md](COMMERCIAL_READINESS.md); this original-scope reconciliation neither implements nor cancels them. Do not expose incomplete packs as selectable finished content.

**Closure rule:** call a feature implemented when code supports it, locally checked when its relevant tests pass, and browser/play verified only when that exact candidate has evidence. Do not call the overall game complete or commercially ready while these release gates remain open.
