# Map workshop

Open **Map workshop → Create a map** to begin with a playable seeded map. Tap to paint grass, forest, water, rock, sand, snow, road, or marsh. Place gold/wood/relic nodes, move two spawns, or erase nodes. Drag to pan; pinch or scroll to zoom.

**Validate** reports unreachable critical features and malformed terrain. **Save** writes the local workshop to IndexedDB. **Export JSON** downloads the complete map. **Import map JSON** reads a map file, validates structure, and opens it for editing. **Test map** starts a skirmish only after validation passes.

This is a working terrain/resource/spawn editor. Direct unit/building placement, arbitrary team assignment, visual trigger editing, multiple saved-map slots, and a configurable authored victory-condition panel are not implemented in this first editor. Campaign authors can currently add units and custom objectives through declarative mission data.
